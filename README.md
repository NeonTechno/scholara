# SCHOLARA

**Your Academic World, One Place.**

SCHOLARA is a mobile-first academic resource hub prototype for ABU students. It organizes learning resources through **Faculty → Department → Level → Semester → Course** and demonstrates search, resource browsing, submissions, and a 7-day trial / $5 monthly subscription flow.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Prototype scope

The current build uses sample course data. Production integration can add authentication, payments, Supabase/Postgres storage, admin moderation, file uploads, YouTube metadata, and the full ABU academic catalogue.
